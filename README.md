## 🧰 Troubleshooting

### 🛠️ "Access Denied" or "Run as Administrator" error
Right-click the application file, select `Properties`, then check `Run this program as an administrator` under the `Compatibility` tab. Then run the file normally.



### 🛠️ Tool says "Defender already disabled" but Defender still active
Reboot your system completely (shut down, then turn on). Windows caches some security service states in memory. A fresh boot ensures all changes take effect.



### 🛠️ Windows Security shows "Red" or "Warning" status
This is expected after disabling Defender. The Windows Security Center will displaya warning banner that Defender is turned off. This does not affect system performance or other functionality. You can hide this alert using Group Policy or simply ignore it.



### 🛠️ Windows Update fails after disabling Defender
Our tool disables Defender-related update components but does not break standard Windows Updates. If you experience update issues, run the `Enable Defender` option, install the updates, then disable Defender again afterward.
